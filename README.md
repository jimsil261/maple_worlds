# 메이플 렉시오

MapleStory Worlds에서 개발 중인 PC용 3·4·5인 멀티플레이 카드 게임입니다. 이동형 카페 프로토타입에서 출발해, 현재는 공개방 목록과 아바타 기반 게임 UI에 집중하는 형태로 개편했습니다.

## 현재 플레이 흐름

게임 시작 → 공개방 목록 → 방 생성·초대 코드 입장 또는 자동 매칭 → 준비 및 카운트다운 → 카드 제출·패스 → 결과 정산

- 공개방 목록: 인원 필터, 6개 단위 페이지, 방 만들기 팝업과 초대 코드 입장
- 자동 매칭: 3인·4인·5인·상관없음 선택
- 대기방과 게임 화면: 실제 유저 닉네임과 아바타 표시
- 게임 화면: 중앙 공개 제출 카드, 6열 2행 손패, 숫자·색 정렬, MY TURN / PASS 표시
- 같은 방 채팅: Enter 전송 및 입력 초기화, 아바타 말풍선
- 규칙 안내: 단계별 설명과 몬스터 카드 족보, 진영 강도 안내
- 배경과 UI: 파스텔 메이플 테마로 통일, 이전 주황색 맵 배경 제거

## 서버 구조

| 역할 | 주요 소스 |
|---|---|
| 조합 판정·비교·점수 계산 | RootDesk/MyDesk/LexioRules.mlua |
| 한 게임의 상태와 종료 정산 | RootDesk/MyDesk/LexioGameSession.mlua |
| 방·좌석·매칭 관리 | RootDesk/MyDesk/LexioTableRegistry.mlua |
| 준비·카운트다운·세션 전이 | RootDesk/MyDesk/LexioSessionCoordinator.mlua |
| 플레이어 요청과 스냅샷 전달 | RootDesk/MyDesk/LexioPlayerBridge.mlua |
| 메인 메뉴·공개방·규칙 안내 | RootDesk/MyDesk/UI/LexioMainMenuController.mlua |
| 카드·아바타·채팅 UI | RootDesk/MyDesk/LexioPlayUIController.mlua |

서버가 좌석 소유권과 플레이 요청을 검증하고, 공개 상태와 개인 손패를 구분해 전달합니다. 테이블별 상태 관리와 중복 요청 방어를 UI와 분리했습니다.

## 점수와 보상

- 64점 기준 원장과 점수 증감 계산, 남은 숫자 2 카드에 따른 배수 처리
- 점수 표현은 1·5·10점 메소 사용
- 게임 점수와 영구 보상 포인트 분리, 사설방은 영구 보상 지급 제외
- 여러 판의 점수 누적 및 결과 화면의 최종 동작은 추가 검증 예정

## 검증 범위와 남은 작업

현재는 개발 중인 프로토타입입니다. Maker 가상 플레이어를 이용해 3·4·5인 화면을 확인했으며, 이는 독립된 여러 클라이언트 검증과 구분합니다.

- 규칙 테스트 50개, 세션·매칭 결정론 테스트 104개 통과는 이전 개발 단계의 기록입니다. 이번 UI 개편에 대해 다시 실행한 결과는 아닙니다.
- 4·5인 아바타와 손패 배치, 채팅 말풍선을 조정했습니다. 공통 하단 버튼 이동 후 전체 화면 재검증은 남아 있습니다.
- 우선 확인: 한 판 완주 → 정산 → 이어 하기, 방 이탈·재입장, 두 방의 상태·채팅 격리, 공개방 페이지 전환
- 후속 작업: 자동 매칭·연결 끊김 및 AI 전환 검증, BGM·효과음
- 이동형 카페·상점·관전은 현재 주요 플레이 흐름에서 제외하거나 후순위로 두었습니다. 관련 소스와 과거 문서는 개발 이력으로 남아 있습니다.

## 실행

1. MapleStory Worlds Maker에서 프로젝트를 엽니다.
2. Workspace를 새로고침하고 Play Test를 실행합니다.
3. 메인 화면의 게임 시작을 누르고 방을 생성하거나 입장합니다.
4. 가상 플레이어로 준비·게임 진행·채팅을 확인합니다.

플랫폼 리소스와 업로드된 이미지 사용에는 MapleStory Worlds 계정 및 해당 리소스 접근 권한이 필요할 수 있습니다.
