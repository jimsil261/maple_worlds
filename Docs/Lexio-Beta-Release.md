# 공개 베타 출시 기록

2026-11-21 MapleStory Worlds 공개 출시 완료 알림을 확인했다. 같은 날 출시본 UI와 효과음 수정도 재출시했다. 11월 24일 이전 베타 공개 목표는 달성했지만 실계정 다인 최종 검증과 지원 자료 완성은 별개다.

- 제목: 메이플 렉시오 / 장르: 캐주얼&아케이드 / 원문: 한국어
- PC 지원. 웹브라우저는 설정 활성화, 실실행 검증 미완료. 모바일·비로그인은 비활성화.
- 현재 출시 설정의 월드 최대 인원 16. 게임 방은 3/4/5인 동적 생성. 무제한 수용을 의미하지 않는다.
- 대표 이미지: [새 썸네일](assets/lexio-beta-thumbnail.png). 기본 이미지와 개발용 스크린샷은 대표 목록에서 제거.
- 별도 앱 종료 버튼 없음. 플랫폼 공식 메뉴에서 로비로 이동.

## 후속 수정

공통 소리 버튼 및 팝업 분리, 실제 클릭 표시 검증, 효과음 100% 최대 배율 수정, 종료 버튼 제거. 최신 검사 경계는 [검증 기록](Verification.md)을 참고한다.

출시 환경의 실계정 다인 플레이·웹 테스트와 시연 영상은 아직 남아 있다. 플레이 URL은 공식 공유 링크를 확인한 뒤 기록한다. 확인하지 않은 URL을 추정해 넣지 않는다.
