# Maple Boardgame Cafe — Phase C1 상세 계획

상태: 구현 준비 완료

## 1. 목표

현재 동작하는 `map01`을 보존하면서 새로운 MapleTile 보드게임 카페 맵의 골격을 만든다. 캐릭터가 메이플스토리 방식으로 좌우 이동·점프하고, 발판·카메라·입구 포탈이 안정적으로 동작하는 첫 번째 탐색 가능한 공간을 완성한다.

## 2. 범위

포함:

- 검증된 MapleTile 템플릿 기반 신규 맵
- `TileMapMode=0`, `RigidbodyComponent`, Foothold 조합
- PC 12.8×7.2 기준 1층 카페 홀과 부분 복층
- 공식 배경·목재 소품 후보를 조합한 첫 시각 패스
- SpawnLocation, 카메라, 기본 이동과 점프
- 기존 로비로 돌아가는 출구
- Maker refresh, build/runtime log, 단일 클라이언트 이동 검증

제외:

- 기존 `map01` 삭제 또는 즉시 교체
- Lexio 세션 연결과 실제 착석
- 최종 테이블·의자 디자인
- 전체 카드 UI 리스킨
- 자동매칭과 추가 보드게임

## 3. 레이아웃

```text
[출구/입구]   [안내 카운터]        [Lexio 구역 예정]
────────────── 1층 주 발판 ─────────────────
          사다리/계단
                └──── 복층 진열장·휴게 공간 ────
```

## 4. 구현 체크리스트

### ⬜ 1. 신규 맵 생성

- MapBuilder의 검증된 MapleTile 템플릿을 사용한다.
- 현재 `map01` 파일과 엔트리를 변경하지 않는다.
- 맵 ID와 모든 엔티티 경로를 신규 카페 이름으로 분리한다.

### ⬜ 2. 지형과 이동

- 주 발판과 복층 발판을 월드 단위로 배치한다.
- 플레이어가 `RigidbodyComponent`를 사용하도록 확인한다.
- 기본 좌우 이동, 점프, 착지, 낙하 방지 경계를 검증한다.
- 카메라는 캐릭터를 따라가되 테이블 구역을 읽을 수 있게 과도한 확대를 피한다.

### ⬜ 3. 첫 시각 패스

- 검색된 공식 배경과 오브젝트를 실제 썸네일 기준으로 검토한다.
- 목재 바닥, 벽, 카운터, 조명, 책장을 우선 배치한다.
- 임시 Lexio 구역 표지만 두고 최종 가구는 C2에서 결정한다.
- 배경·중경·전경 SortingLayer와 OrderInLayer를 분리한다.

### ⬜ 4. 출입과 검증

- 신규 카페 내부 출구를 기존 로비 복귀 경로에 연결한다.
- Maker refresh 후 build 오류가 없는지 확인한다.
- Play에서 좌우 이동·점프·발판 착지·출구를 확인한다.
- 현재 `map01`의 3인 Lexio 흐름이 변경되지 않았음을 확인한다.

## 5. 완료 기준

- 새 카페 맵이 MapleTile 모드로 로드된다.
- 캐릭터가 메이플 방식으로 자연스럽게 이동하고 점프한다.
- 카페 공간이 빈 테스트 맵이 아니라 목재 실내 공간으로 읽힌다.
- 기존 플레이 가능한 Lexio 맵은 그대로 남아 있다.
- 빌드와 런타임 오류가 없다.
