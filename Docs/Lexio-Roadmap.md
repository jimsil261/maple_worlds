# 후속 로드맵

기준: 2026-11-21 공개 베타. 현재 기능과 검증은 [현재 상태](Current-Status.md)를 따른다.

## 우선순위

1. 실계정 3인 전체 한 판·재경기·이탈·투표·복귀 확인, 이후 4/5인 확대.
2. 두 방 동시 플레이로 개인 손패와 채팅·점수 격리 확인.
3. 웹브라우저 실제 실행과 플랫폼 음량·리소스 표시 확인.
4. 시연 영상 및 검증된 플레이 링크를 지원 문서에 추가.
5. 장시간 플레이·오류 로그·사용자 피드백 정리.

## 선택적 확장

BGM 선택, 채팅에 따른 표정, 관전·순위·추가 보드게임. 영구 보상/코디 상점은 현재 폐기한 출시 범위이며 도입을 확정하지 않았다. 인스턴스 간 방 목록·복구는 별도 설계가 필요하다.

초기 GDD·Phase 문서는 카페 시제품의 설계 이력으로 보존한다. 현재 제한으로 적혀 있던 ‘3/4/5인 방 각각 하나’는 동적 방 생성으로 해소했으며, 실제 동시 사용자 수·성능 한도까지 검증한 뜻은 아니다.
