# 현재 개발 상태 — 2026-11-13

## 확정한 방향

PC 전용 UI 기반 렉시오에 집중한다. 캐릭터 이동형 카페 대신 같은 배경 위에서 메인 메뉴, 공개방 목록, 대기방, 게임 화면을 전환한다. 유저 아바타와 닉네임은 유지하며 3·4·5인에 맞춰 배치한다.

## 이번 저장 범위

- 공개방 필터·페이지, 방 생성 팝업, 초대 코드 입장 및 준비 흐름
- 아바타 표시와 닉네임, MY TURN / PASS, 몬스터 카드 및 족보 안내
- 같은 방 채팅, Enter 전송과 입력 초기화, 아바타 말풍선
- 4·5인 UI 간격과 이름표, 손패 6열 2행, 하단 정렬·제출·패스 배치
- 이전 주황색 맵 Background 엔티티와 실내 SpriteRenderer 제거. 게임 호스트와 발판은 보존
- 기존 커밋 이력 보존, README를 현재 게임 방향으로 교체
