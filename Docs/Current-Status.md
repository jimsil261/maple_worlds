# 현재 상태 - 2026-11-21 공개 베타

현재 제품은 PC용 정적 UI 기반 메이플 렉시오다. 카페 이동·NPC·코디 상점·영구 보상 설계는 출시 범위에서 제외했다.

## 반영 완료

- 공개 베타 출시 및 후속 UI·사운드 수정본 출시 완료 알림 확인.
- 3·4·5인 각 12장, 동적 다중 방, 방장·설정·비밀번호, 목록 페이지와 기존 방 우선 매칭.
- 15초 턴, 서버 정산, 재경기 점수 이월과 만장일치.
- 이탈 시 일시 정지, 30초 과반 초과 AI 대행 투표, 미투표 반대, 기존 소유자 재접속.
- 종료 시 AI가 남으면 정산 후 방 닫기. 전원 이탈·빈 방 회수.
- 채팅·말풍선·필터, 족보, 카운트다운·턴 음성, 공통 소리 설정.
- 소리 팝업을 게임 HUD에서 공통 UI로 분리. 출시 클라이언트 실제 마우스 클릭으로 표시 확인.
- 효과음의 낮은 기본 배율 제거: 게임 설정 100%가 SoundService 인자 1.0에 대응. 플랫폼 자체 음량은 별도다.
- 사용자 요청에 따라 메인화면 게임 종료 버튼 제거. 플랫폼 ··· 메뉴의 로비로 이동 사용.

## 검증

최신 독립 검사: 규칙 50 + 세션 108 + 추가 시나리오 3,467 = 3,625개 단언 통과. 최근 메뉴·음량 변경으로 달라진 테스트 기대값을 갱신 후 재실행했다. 최신 Maker 빌드/실행 오류·경고 0 기록은 [검증 기록](Verification.md)을 참고한다.

## 남은 확인

- 독립 실계정 여러 명의 입장·손패/RPC·채팅 격리·끊김·복귀·종료·재경기 전체 흐름.
- 웹브라우저 실제 실행, 음원 재생과 리소스 표시. 출시 설정에서만 활성화한 상태다.
- 다른 월드 서버 인스턴스로 재접속했을 때 복구, 인스턴스 간 통합 매칭은 미지원.
- 실제 체감 음량과 기기별 UI, 장시간 운영·부하 검증.

비로그인 플레이는 비활성화했다. 전용 앱 강제 종료 API 대신 추방으로 종료하던 임시 처리는 제거했다. 과거 문서보다 이 문서와 README를 현재 상태의 기준으로 삼는다.

## 2026-11-22 업데이트

새 내 차례에 이전 제출·오류 안내를 비우고 패스 버튼의 공통 클릭음을 제외했다. 독립 검사 3,625개 단언 통과, Maker 참가 상태에서 안내 초기화와 패스 중복 연결 제외를 확인한 뒤 재출시 완료 알림을 확인했다.
