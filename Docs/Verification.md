## 독립 검사 실행

```sh
npm ci --prefix tests/lexio-validation
node tests/lexio-validation/run.cjs
```

Fengari로 실제 mLua 메서드 본문을 실행한다. 클래스·타입·실행공간 표기는 하네스가 제거하고 Entity/RPC/일부 서비스는 작은 대역을 사용한다. 게임 로직을 별도로 재작성하지 않는다. node_modules는 커밋하지 않는다.

대표 검사: 방 소유권/이전 방 정리, 매칭 순서, 결과 시점 AI 정책, 재접속, 엄격한 과반·미투표 처리, 재경기 점수·제로섬, UI 요청 연결, 개별 음량과 비속어 필터.

## 출시 후 발견과 수정

1. 직접 이벤트 전송 검사는 소리 팝업의 Enable 값만 확인해 실제 가림 문제를 놓쳤다. 출시본 마우스 클릭으로 재현 후, 팝업을 공통 UI로 옮기고 출시본에서 실제 표시를 확인했다.
2. 게임 종료에 KickUser를 쓰면 추방 문구가 발생했다. 공식 조용한 종료 API를 확인하지 못했고, 임시 처리를 제거한 뒤 사용자 요청으로 종료 버튼 자체를 숨겼다.
3. 효과음 100%가 기존 0.18/0.3/0.65 배율에 곱해졌다. 1.0 기준으로 변경하고 재생 인자를 검증했다. 플랫폼 자체 볼륨은 사용자 설정을 유지했다.
4. 종료 시 DisconnectEvent 인자가 빠진 기존 코드를 수정하고 시작·종료 모두 오류가 없는지 확인했다.

검사 수가 많다는 이유로 모든 실환경 동작을 보장하지 않는다. 다음 검증은 독립 실계정 다인 플레이와 실제 웹 실행이다.
